## Why

현재 멤버 초대는 요청 즉시 접근 권한을 부여하므로 수신자가 동의하지 않은 공유가 발생할 수 있습니다. 이메일 초대 링크에서 수락 또는 거절을 명시적으로 선택하도록 바꿔 초대 의사와 실제 접근 권한을 분리합니다.

## What Changes

- 새 초대를 `pending` 상태로 저장합니다.
- 초대 대상 계정만 초대를 수락하거나 거절할 수 있는 API를 추가합니다.
- 수락한 초대만 문서·화이트보드 접근 권한과 실시간 편집 권한을 가집니다.
- 초대 이메일 링크를 수락·거절 화면으로 연결합니다.
- 기존 상태 필드가 없는 멤버 데이터는 승인된 멤버로 호환합니다.

## Capabilities

### New Capabilities

- `invitation-acceptance`: 이메일 기반 작업 공간 초대의 대기·수락·거절 상태와 접근 권한 전환

### Modified Capabilities

- 없음

## Impact

- Collab server의 멤버 타입, 영속 저장소, 접근 판정, 문서·화이트보드 멤버 API
- Collab web의 초대 화면과 이메일 링크
- 기존 멤버 데이터 마이그레이션 없이 하위 호환 처리
