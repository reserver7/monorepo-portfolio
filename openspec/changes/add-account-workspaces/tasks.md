## 1. 계약과 인증

- [ ] 1.1 문서·화이트보드 타입과 저장 정규화에 nullable `ownerId`를 추가하고 기존 상태 호환 테스트를 통과시킨다.
- [ ] 1.2 Collab 서버에서 OpsLens 서명 세션을 검증해 현재 사용자 컨텍스트를 만들고 위조된 `ownerId`를 거부하는 테스트를 통과시킨다.

## 2. 서버 기능

- [ ] 2.1 문서·화이트보드 목록 API를 인증 사용자 및 시스템 소유 레코드로 필터링하고 API 테스트를 통과시킨다.
- [ ] 2.2 문서·화이트보드 생성 API가 검증된 사용자 ID를 저장하도록 변경하고 생성 테스트를 통과시킨다.
- [ ] 2.3 소유자 삭제와 레거시 보호 키 삭제를 분리하고 타인 레코드 삭제가 403인지 테스트한다.
- [ ] 2.4 파일·Supabase 상태 저장과 재시작 후 ownerId 보존을 검증한다.

## 3. 웹 기능

- [ ] 3.1 HttpOnly 세션을 읽는 Collab 웹 서버 프록시 API를 추가하고 브라우저에 비밀값이 노출되지 않는 테스트를 통과시킨다.
- [ ] 3.2 문서·화이트보드 홈 목록과 생성·삭제 클라이언트를 계정별 프록시에 연결하고 다른 사용자 데이터가 보이지 않는 UI 테스트를 통과시킨다.

## 4. 통합 검증

- [ ] 4.1 기존 실시간 문서·화이트보드 방 흐름과 새 계정별 CRUD를 함께 실행해 회귀 테스트를 통과시킨다.
- [ ] 4.2 `openspec validate --change add-account-workspaces --strict`, 관련 단위/통합/E2E 테스트, 웹 빌드를 실행해 배포 가능한 상태를 확인한다.
