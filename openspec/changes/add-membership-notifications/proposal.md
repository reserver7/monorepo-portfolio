## Why

활동 로그는 작업 공간 소유자만 확인할 수 있어, 멤버 개인은 자신의 권한 변경이나 작업 공간 변경을 알기 어렵습니다.

## What Changes

- 계정별 멤버십 알림을 저장합니다.
- 읽지 않은 알림 수와 최근 알림 목록을 제공합니다.
- 알림 읽음 처리를 지원하는 전역 알림 센터를 추가합니다.

## Capabilities

### New Capabilities

- `membership-notifications`: 멤버십 변경 알림

## Impact

- Collab 저장소·알림 API
- 웹 전역 알림 센터
- 멤버십 이벤트 처리
