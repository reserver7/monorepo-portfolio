## Purpose

작업 공간 초대 알림을 제공하되 무료 사용 한도를 넘거나 결제 설정으로 이어지지 않도록 발송 조건을 엄격하게 제한합니다.

## ADDED Requirements

### Requirement: 무료 발송 보호

이메일 발송 기능은 기본적으로 비활성화되어야(SHALL) 하며, 활성화된 경우에도 월 발송량을 3,000통 이하로 제한해야(SHALL) 합니다.

#### Scenario: 기본 비활성

- **WHEN** 발송 활성화 환경 변수가 설정되지 않았습니다.
- **THEN** 멤버 초대는 성공하지만 외부 이메일 API는 호출하지 않습니다.

#### Scenario: 무료 한도 도달

- **WHEN** 해당 월 발송량이 3,000통에 도달했습니다.
- **THEN** 다음 초대에서 외부 이메일 API를 호출하지 않습니다.

### Requirement: 안전한 초대 발송

활성화된 발송은 검증된 발신 주소와 API 키가 있을 때만 실행되어야(SHALL) 하며, 발송 실패가 멤버 등록을 취소해서는 안 됩니다(MUST NOT).

#### Scenario: 설정 누락

- **WHEN** 활성화는 되었지만 API 키 또는 발신 주소가 없습니다.
- **THEN** 멤버 등록은 유지하고 이메일은 보내지 않습니다.

#### Scenario: 정상 발송

- **WHEN** 유효한 설정과 무료 한도 잔여량이 있습니다.
- **THEN** 초대 대상 이메일과 작업 공간 링크를 포함한 이메일을 한 통 발송하고 사용량을 증가시킵니다.
