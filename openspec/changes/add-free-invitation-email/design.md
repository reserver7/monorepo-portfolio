## Context

Collab 서버는 멤버 초대를 자체 상태 JSONB에 저장하며 별도 메일 서비스가 없습니다. 무료 사용을 보장하기 위해 유료 SDK나 자동 결제 설정은 추가하지 않습니다.

## Goals / Non-Goals

**Goals:**

- Resend HTTP API를 선택적으로 호출합니다.
- 기본 비활성, API 설정 검증, 월 3,000통 상한을 적용합니다.
- 메일 장애가 핵심 멤버십 기능을 막지 않게 합니다.

**Non-Goals:**

- 마케팅 메일과 대량 발송
- 유료 플랜 자동 전환 또는 결제수단 등록
- 이메일 수락 전까지 멤버십을 보류하는 별도 초대 상태

## Decisions

- SDK 대신 Node 기본 `fetch`를 사용해 의존성을 늘리지 않습니다.
- `RESEND_ENABLED=false`를 기본값으로 두고 운영에서 명시적으로 켠 경우에만 발송합니다.
- 발송 상한은 설정값이 더 크게 입력되어도 3,000통으로 clamp합니다.
- 발송은 멤버 저장 후 비동기로 수행하며 실패는 로그만 남깁니다.

## Risks / Trade-offs

- [Risk] 프로세스 재시작 시 사용량 카운터가 초기화될 수 있습니다. → 기본 비활성으로 두고 Resend 무료 플랜 자체의 한도도 함께 적용합니다. 사용량 추적이 필요해지면 Supabase 카운터로 이동합니다.
- [Risk] 발신 도메인 검증이 없으면 Resend가 거부할 수 있습니다. → 설정 누락/실패를 멤버 등록과 분리합니다.
