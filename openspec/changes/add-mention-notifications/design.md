## Context

계정별 알림 저장·조회·실시간 갱신은 이미 구현되어 있고, 댓글은 멘션 문자열을 저장합니다.

## Decisions

- 승인된 문서 멤버의 계정 ID·이메일·이메일 local-part와 멘션 토큰을 비교합니다.
- 댓글 생성 시에만 멘션 알림을 만들고, 댓글 편집으로 새 멘션을 추가하는 동작은 다음 범위로 둡니다.
- HTTP 댓글 생성과 Socket.IO 댓글 생성 모두 같은 저장소 함수를 사용합니다.
- 알림에는 `commentId`를 저장하고 문서 URL의 query parameter로 전달해 댓글 패널이 해당 댓글을 강조합니다.
- 댓글 수정 시 이전 멘션 목록과 비교해 새로 추가된 토큰만 알림 대상으로 사용합니다.
- 문서 댓글 패널은 승인된 멤버 API에서 이메일 local-part를 받아 멘션 후보로 표시합니다.

## Non-Goals

- 이메일 멘션 발송
- 화이트보드 댓글 기능 추가
